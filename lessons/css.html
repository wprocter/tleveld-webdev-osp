1. Cascade & Specificity

Understanding how the browser decides which rule wins is essential. Origin, importance, specificity and order all matter.

/* Specificity examples */
#banner span { color: hotpink; }
.card span { color: teal; }
span { color: gray; }
Tip: Avoid over-specific selectors; keep them short and purposeful.

2. Box Model

Every element is a rectangle composed of content, padding, border, and margin. The box-sizing property changes how width/height are calculated.

* { box-sizing: border-box; }
.card { padding:1rem; border:1px solid #333; }
Checklist: Using box-sizing:border-box globally reduces layout headaches.

3. Flexbox

Flexbox excels at one-dimensional alignment (rows OR columns), distributing space and centering with minimal code.

.toolbar {
  display:flex;
  align-items:center;
  gap:.75rem;
}
Remember: Use flex:1 to let items grow; combine with min-width to avoid squashing.

4. CSS Grid

Grid provides true two-dimensional layout with explicit and implicit tracks. Define rows/columns and place items deliberately.

.gallery {
  display:grid;
  grid-template-columns:repeat(auto-fit,minmax(180px,1fr));
  gap:1rem;
}
Tip: Use minmax() with auto-fit or auto-fill for fluid responsive grids.

5. Responsive Design

Use relative units, fluid grids, and media queries to adapt layout across breakpoints.

@media (min-width: 768px){
  .sidebar { display:block; }
}
Checklist: Test at narrow, medium and very wide widths; watch for orphaned content or overflow.

6. Best Practices

  • Keep selectors shallow & modular.
  • Favour layout systems (Flex/Grid) over absolute positioning.
  • Reuse custom properties for consistency.
  • Audit contrast and tap targets.
  • Remove unused CSS regularly.
