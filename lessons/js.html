1. Variables & Types

Use const for values that shouldn't be reassigned, let for reassignable bindings. Primitive types include string, number, boolean, null, undefined, symbol, bigint.

const name = 'Ada';
let count = 0;
count++;
Tip: Prefer const by default; it signals intent.

2. DOM Manipulation

The Document Object Model represents the page so scripts can change structure, style, and content.

const list = document.querySelector('#tasks');
list.insertAdjacentHTML('beforeend', '
  • New Task
    • ');
    Checklist: Cache selectors; avoid unnecessary reflows.

    3. Events

    Events are signals from the browser or user. Event delegation improves performance by listening high in the tree.

    document.addEventListener('click', e => {
  if(e.target.matches('.delete')) removeItem(e.target);
});
    Remember: Remove listeners for long-lived single-page sessions when not needed.

    4. Fetch & JSON

    The Fetch API returns promises for HTTP requests. Always handle errors and unexpected statuses.

    try {
  const res = await fetch('/data');
  if(!res.ok) throw new Error(res.status);
  const data = await res.json();
} catch(err){
  console.error(err);
}
    Tip: Use AbortController to cancel slow requests.

    5. Async / Await

    async functions return promises; await pauses until a promise settles, making asynchronous code read linearly.

    async function load(){
  const res = await fetch('/api/time');
  return res.json();
}
    Checklist: Wrap awaits in try/catch to handle rejection paths.

    6. Good Practices

    • Limit global variables.
    • Keep functions small & focused.
    • Use strict equality (===).
    • Handle errors (try/catch / .catch()).
    • Profile performance for hot paths.
