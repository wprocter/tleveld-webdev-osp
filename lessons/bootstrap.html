1. Why Bootstrap

Bootstrap provides a consistent design system, responsive grid and pre-styled components reducing development time.

Tip: Understand the underlying CSS; don't rely blindly on classes.

2. Grid System

The grid uses containers, rows and columns. Breakpoints adapt column stacking.

<div class="row">
  <div class="col-12 col-md-6">Left</div>
  <div class="col-12 col-md-6">Right</div>
</div>
Checklist: Use .g-* classes to manage gutters consistently.

3. Utility Classes

Utilities offer single-purpose helpers (spacing, display, flex, colours) enabling rapid iteration without writing custom CSS.

<div class="d-flex align-items-center justify-content-between gap-3">...</div>
Remember: Avoid utility bloat by refactoring repeated chains into a class.

4. Core Components

Alerts, modals, navbars, cards and forms provide accessible building blocks. Initialise JS components via data attributes or the API.

<button class="btn btn-primary" data-bs-toggle="modal" data-bs-target="#demo">Open</button>
Tip: Keep custom overrides minimal to ease framework updates.

5. Customisation

Override Sass variables or use CSS custom properties for themes. Remove unused components for lean bundles.

$primary: #ff6a3d;
@import "bootstrap";
Checklist: Always document design tokens when theming.

6. Integration Tips

  • Load CSS early; bundle/minify in production.
  • Defer or bundle JS; only include needed plugins.
  • Keep custom CSS scoped.
  • Use accessible markup patterns.
  • Test components with keyboard and screen reader.
