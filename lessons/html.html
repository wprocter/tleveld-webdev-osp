1. Document Structure

The HTML document begins with a doctype and an <html> element that wraps the <head> and <body>. The head contains metadata; the body contains what users see and interact with.

<!doctype html>
<html lang="en">
  <head>
    <meta charset="utf-8" />
    <title>My Page</title>
  </head>
  <body>
    <h1>Hello World</h1>
  </body>
</html>
Tip: Always set the lang attribute; it helps screen readers pick correct pronunciation rules.

2. Semantic Tags

Semantic elements express meaning (purpose) rather than presentation. This aids accessibility, SEO, and maintainability.

<header>

Intro or top section of a page/section.

<nav>

Primary navigation landmarks.

<main>

Unique main content of the page.

<article>

Self-contained composition (blog, card).

<section>

Thematic grouping of content.

<aside>

Tangential / complementary content.

3. Text Elements

Headings create an outline (never skip levels for style). Lists group related items, and inline elements like <strong> and <em> convey meaning, not appearance.

Checklist: Is your heading order logical? Are lists used instead of repeated <br>? Are emphasised words meaningful?

4. Forms

Forms collect user input with accessible labels and clear grouping.

<form action="/subscribe" method="post">
  <label for="email">Email</label>
  <input id="email" name="email" type="email" required />
  <button class="btn btn-accent">Join</button>
</form>
Remember: Use type="email", required, and proper labels to reduce errors and boost usability.

5. Accessibility Essentials

  • Provide alt text for informative images.
  • Use labels and/or aria-labelledby for interactive controls.
  • Ensure sufficient colour contrast (AA minimum).
  • Logical heading hierarchy.
  • Keyboard focus visible.
