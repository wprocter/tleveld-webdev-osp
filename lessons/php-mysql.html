1. Environment Setup

Use a local stack (XAMPP, MAMP, or Docker) to run Apache, PHP and MySQL. Ensure PDO and mysqli extensions are enabled.

Tip: Use environment variables or a config file for credentials — never commit secrets.

2. PHP Basics

PHP scripts run on the server and output HTML. Variables start with $. Arrays and associative arrays are first-class citizens.

<?php
$name = "Dev";
echo "Hello $name";
?>
Checklist: Enable error reporting in dev (error_reporting(E_ALL);) turn off in production.

3. Database Connection

Prefer PDO for prepared statements and portability.

<?php
$pdo = new PDO('mysql:host=localhost;dbname=demo','user','pass');
$pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
?>
Remember: Always set error mode to exceptions for safer failure handling.

4. CRUD Operations

Create, Read, Update, Delete using prepared statements to avoid SQL injection.

$stmt = $pdo->prepare('INSERT INTO posts(title) VALUES (?)');
$stmt->execute(['Hello']);
Tip: Reuse prepared statements for repeated inserts.

5. Security & Safety

  • Prepared statements for all external input.
  • Escape output (HTML entities) when injecting into HTML.
  • Hash passwords with password_hash().
  • Validate and sanitise all form data.
  • Principle of least privilege for DB user.

6. Next Steps

Look into routing, templating engines, ORMs, and frameworks (Laravel, Symfony) for larger applications.
